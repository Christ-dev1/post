# Post-it

## Description

ce projet est une application web qui permet de gérer des Post-it

## Fonctionnalite

on peut :
- ajouter une note
- Voir les notes
- modifier une note
- supprimer une note

le projet utilise vue.js  avec TailwindCSS et un peu de css pour le design.

---
## Technologies utilisées

- Vue-js
- TailwindCSS
- Vite
- Javascript

---

## installation


1- Cloner le projet : 
git clone git@github.com:EpitechCodingAcademyPromo2026/C-DEV-121-ABJ-1-1-postit-4.git

2- Ouvert le dossier :
cd post-it

3- installation des ressources :
npm install


4- Lancer le projet :
npm run dev

---

## fonctionnement

les notes sont récupérées depuis une Api
Chaque note a une couleur différente
